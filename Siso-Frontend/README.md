# SDST - Sistema de Detección Sísmica Temprana (Tucumán)

Aplicación web interactiva desarrollada en *React* y *Vite* orientada al monitoreo, prevención e información en tiempo real sobre la actividad sísmica en la provincia de Tucumán y el resto del mundo.

---

## 🚀 Características Principales

* *Monitoreo Sísmico en Tiempo Real:* Integración con la API pública de la *USGS (United States Geological Survey)* para listar eventos sísmicos recientes.
* *Guía de Hospitales y Emergencias:* Mapa e información de centros de salud y líneas telefónicas útiles de la provincia de Tucumán (107, 911, etc.).
* *Protocolos de Actuación:* Información didáctica sobre qué hacer antes, durante y después de un sismo, junto con la clasificación de tipos de sismos.
* *Interfaz Adaptativa:* Maquetación responsiva utilizando *React-Bootstrap* y estilos modernos.
* *Pantalla de Carga (SplashScreen):* Animación de entrada para una mejor experiencia de usuario.

---

## 🛠️ Tecnologías Utilizadas

* *Frontend:* React 18
* *Build Tool:* Vite
* *Estilos:* Bootstrap 5 & React-Bootstrap, CSS customizado
* *Peticiones HTTP:* Axios
* *Enrutamiento:* React Router DOM (v6)
* *Alertas e Iconos:* SweetAlert2 & Font Awesome
* *Manejo de Versiones:* Git & GitHub
